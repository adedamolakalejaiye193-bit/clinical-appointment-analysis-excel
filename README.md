# clinical-appointment-analysis-excel

## Project Overview

This project analyses clinical appointment. The dataset includes gender, age, appointment date, department, visit type, attended, current waiting time, weekly capacity, cost.

## The goal of this project was to:

- Is to analyse clinical appointment data to identify departments experiencing long patient waiting times, high missed appointment rates, and
  demand that exceeds weekly appointment capacity.

- Using Excel, lookup formulas, PivotTables, PivotCharts, and a dashboard, the project explores appointment attendance patterns, compare
  scheduled appointments against departmental capacity, and highlights areas that may require operational improvement.

- The aim is to turn raw healthcare data into actionable insights that can support better resource allocation, improve appointment management,
  reduce missed appointments, and help hospital management make informed, data-driven decisions about patient access and service delivery.

  ## Dataset
- AI generated data by HEALTH DATA-IQ
- Size: 70 patient records

## Key Features
- Patient ID
- Patient Name
- Age
- Gender
- Department(Cardiology, Dermatology, General Practice, Paediatrics, Radiology)
- Appointment Date 
- Attended (YES, NO)
- Cost
- Visit Type

## Methods & Tools
- Tools: Google Sheets(Excel)
## Technique:
- Data cleaning and standardization
- PivotTable to summarise trends
- PivotCharts for visualisation

## Key Findings
- ⁠Longest waiting times: Cardiology and Dermatology have the longest current waiting times, at 12 days.
-  ⁠Missed appointments: The dashboard highlights missed appointments by department, helping identify areas where attendance may need improvement.
- ⁠Capacity pressure: The scheduled appointments versus weekly capacity dashboard identifies departments where appointment demand exceeds available capacity.
- ⁠Operational priorities: Cardiology and Dermatology should be reviewed alongside departments experiencing high missed appointment rates or capacity pressures.
- ⁠Management recommendations: The analysis can support decisions about appointment scheduling, resource allocation, and improving patient access.
